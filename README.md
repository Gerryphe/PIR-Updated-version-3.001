1. install node js (v9.9.0) https://nodejs.org
2. restart pc
3. install gulp. Type in console npm install -g gulp
4. restart pc
5. open console in project folder
6. npm i - install all modules from package.json
7. index.js file from project foder copy to node_modules\gulp-filelist\
8. gulp clean - clr destination folder
9. gulp build - build project 
10. gulp buildGz - build project with Gzip compression 
11. dest folder - compressed web interface
11. dest\bin folder - binary files for mcu
12. dest\bin\http_serv_fse.cpp - copy this file to project folder, contains all web interface
